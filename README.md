# Todo App

A straightforward Todo application built with **React**, **Vite**, and **Redux Toolkit** for state management.

## Features
* Add todos
* Update todos
* Toggle complete / incomplete status
* Delete todos
* Global state managed entirely by Redux

## How to Run

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run development server:**
   ```bash
   npm run dev
   ```
